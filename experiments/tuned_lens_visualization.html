Tuned Lens

Reading Every Layer of Llama-3.2-3B

An interactive mathematical walkthrough · Based on nostalgebraist-lol & belrose et al. (arXiv:2303.08112)

Core idea: Train a simple affine probe at each layer so we can "read off" the model's next-token prediction from any intermediate representation.

1 — The Problem

A transformer with L layers builds up a residual stream at each layer:

h0  →  h1  →  h2  →  …  →  hL  →  output

Each  hℓ ∈ ℝ3072  (for Llama-3.2-3B)

The question

What does each layer "know" about the next token? Is the final prediction already encoded at layer 2, or does genuine computation happen in later layers?

2 — Logit Lens (Baseline)

The simplest approach: just apply the final layer's unembedding directly to any intermediate representation.

hℓ
Residual stream
→
LNfinal(·)
Layer norm
→
WU · (·) + bU
Unembed
→
softmax
→ plogit
Problem: Early layers haven't aligned their representations to the unembedding space. The logit lens produces KL > 1.5 at layer 2 — essentially garbage.

Layers 0–1 produce ∞ KL (distribution collapse / numerical overflow). 
// Logit lens implementation (no training needed)
def apply_logit_lens(activations, model, concept_ids):
    normed = model.ln_final(activations)       # Final layer norm
    logits = normed @ W_concept + b_concept      # Unembed (concept subset)
    return F.softmax(logits, dim=-1)           # → probabilities

3 — Tuned Lens: The Mathematics

The Translator

Insert a learned affine transformation before the logit lens:

Tℓ(hℓ) = Wℓ · hℓ + bℓ

Wℓ ∈ ℝd×d,   bℓ ∈ ℝd,   d = 3072

Identity Initialization

Wℓ(0) = Id      bℓ(0) = 0

At initialization, Tℓ(h) = h — identical to the logit lens!
Training starts from the logit lens baseline and learns corrections.

Training Objective

ℒℓ = DKL( pℓlens ‖ pfinal )

Minimize the KL divergence between the lens distribution and the model's actual final-layer output. This is computed over the full vocabulary (~128K tokens), not just the 3 HMM concept tokens.

Per-Layer Independence

Each of the 28 layers gets its own translator — no shared parameters. This allows clean layer-by-layer analysis of information flow.

Total parameters per translator: d² + d = 3072² + 3072 = 9,440,256
(compare: full model has ~3.2B parameters)

# For each layer independently:
translator = TunedLensTranslator(d_model=3072)
optimizer  = Adam(translator.parameters(), lr=0.001)
scheduler  = CosineAnnealingLR(optimizer, T_max=50)

for epoch in range(50):
    for batch in dataloader(activations, batch_size=512):
        h     = translator(batch)                # W·h + b
        normed = model.ln_final(h)               # Final layer norm
        logits = normed @ W_U + b_U              # Full-vocab logits
        log_p  = log_softmax(logits)             # ~128K-dim log-probs

        loss = kl_div(log_p, target_log_probs,  # KL(p_lens || p_final)
                     reduction="batchmean",
                     log_target=True)
        loss.backward()
        optimizer.step()

5 — Implementation Deep-Dive

The TunedLensTranslator class

class TunedLensTranslator(nn.Module):
    """Per-layer affine translator h_l → h̃, identity-initialized.

    Following arXiv:2303.08112, the translator is initialized as
    the identity so training starts from the logit-lens baseline."""

    def __init__(self, d_model: int):
        super().__init__()
        self.linear = nn.Linear(d_model, d_model, bias=True)
        nn.init.eye_(self.linear.weight)     # W = Identity
        nn.init.zeros_(self.linear.bias)    # b = 0

    def forward(self, x):
        return self.linear(x)               # Wx + b

Applying the Tuned Lens

def apply_tuned_lens(activations, translator, model, concept_ids):
    """h → T(h) → LN_final → softmax(W_U · LN(T(h)) + b_U)"""
    W_concept = model.unembed.W_U[:, concept_ids]  # Concept subset
    b_concept = model.unembed.b_U[concept_ids]

    with torch.no_grad():
        h      = translator(activations)       # Affine transform
        normed = model.ln_final(h)              # Layer norm
        logits = normed @ W_concept + b_concept  # → concept logits
        return F.softmax(logits, dim=-1)       # → P(A), P(B), P(C)

Key design choice: Full-Vocabulary Training

Training uses all ~128K tokens in the vocabulary, not just the 3 HMM concepts. This is faithful to the original paper and ensures the translator learns the true geometry of the representation space.

At evaluation time, we project onto just the 3 concept tokens {A, B, C} to compare with HMM ground truth.

7 — Key Insights

1 Even layer 0 achieves 97% top-1 agreement with the final model after an affine correction. The information is there — it's just misaligned.
2 KL drops from 0.012 → 0.001 across layers. Later layers perform genuine new predictive computation — they don't just re-express what earlier layers already computed.
3 Belief-state R² peaks at layer 2 (0.999), but the tuned lens keeps improving toward the final layer. Interpretation: later layers re-encode representations away from the belief simplex and toward unembedding alignment.
4 Logit lens fails catastrophically at early layers (KL > 1.5), while the tuned lens stays below 0.05 everywhere. The affine correction is both necessary and sufficient.
5 Information is not lost — it's re-encoded. The tension between R² (peaks early) and tuned lens KL (improves late) shows that later layers transform the representation for readout, not for belief-state geometry.
